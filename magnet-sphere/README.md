# magnet-sphere — 磁石で割れる球体 STL

断面を磁石で吸着する分割球体。断面は完全に平ら（ベッド面仕上げ）で、磁石は印刷中の一時停止で内部に完全埋め込み式（`*_embed`）と、印刷後に差し込む簡単式（`*_openface`）の2系統。

ポケットは3等配＋内側1個の4個配置。断面は平らなのでどの角度でも閉じる（4組が揃う向きが最強）。

| フォルダ | 内容 | 構成 |
|---|---|---|
| `sphere150/` | **本番 Ø150mm**・平行5層（30mmスラブ×5） | STL3種を計5個印刷、推定350〜450g（概算） |
| `sphere50/` | モック Ø50mm・半球2分割 | 同じSTLを2個印刷、推定40〜50g（概算） |
| `sphere200/` | Ø200mm・平行5層（参考・大きい版） | STL3種を計5個印刷、推定700〜850g（概算） |
| `src/` | 生成スクリプト（trimesh+manifold3d） | `gen_slab_sphere.py 150｜200`、`gen_sphere.py`（Ø50）。既定で各フォルダへ出力 |

磁石は全サイズ共通で **丸型ネオジム φ10mm×3mm（N35以上）** を想定（sphere50には6×3/5×2/8×3版もあり）。
印刷は P1S + Bambu Studio 前提。重量は概算なので、スライス後の重量表示で確定させる。**作り方は [HOWTO_手順書.md](HOWTO_手順書.md)**（Bambu Studio の操作を含む全手順）。数値の根拠は各フォルダの GUIDE を参照。
