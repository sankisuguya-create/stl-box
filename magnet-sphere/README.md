# magnet-sphere — 磁石で割れる球体 STL

断面を磁石で吸着する分割球体。断面は完全に平ら（ベッド面仕上げ）で、磁石は印刷中の一時停止で内部に完全埋め込み式（`*_embed`）と、印刷後に差し込む簡単式（`*_openface`）の2系統。

ポケットは3等配＋ずらした「合い印」1個の4個配置 → 各断面は1通りの向きでしか閉じない。

| フォルダ | 内容 | 構成 |
|---|---|---|
| `sphere150/` | **本番 Ø150mm**・平行5層（30mmスラブ×5） | STL3種を計5個印刷、推定250〜350g |
| `sphere50/` | モック Ø50mm・半球2分割 | 同じSTLを2個印刷、約65g |
| `sphere200/` | Ø200mm・平行5層（参考・大きい版） | STL3種を計5個印刷、推定600〜800g |
| `src/` | 生成スクリプト（trimesh+manifold3d） | サイズ・磁石寸法を変えて再生成可 |

磁石は全サイズ共通で **丸型ネオジム φ10mm×3mm（N35以上）** を想定（sphere50には6×3/5×2/8×3版もあり）。
印刷は P1S + Bambu Studio 前提。手順・一時停止の層・磁石の向きルールは各フォルダの GUIDE を参照。
