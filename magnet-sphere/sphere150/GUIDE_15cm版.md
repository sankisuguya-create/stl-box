# 直径15cm・平行5層スライス球体 STLキット（本番版）

Ø150mmの球を30mm厚の平行スラブ5枚に切ったもの。断面同士は磁石で吸着。
STLは**3種だけ**（合計5個印刷）：

| STL | 印刷数 | 使う場所 | 断面 |
|---|---|---|---|
| `sphere150_cap_m10x3_*.stl` | 2 | 一番下(1層目)・一番上(5層目) | 片側Ø120 |
| `sphere150_edge_slab_m10x3_*.stl` | 2 | 2層目・4層目 | 下Ø120／上Ø147 |
| `sphere150_mid_slab_m10x3_*.stl` | 1 | 3層目(中央) | 両側Ø147 |

- `*_embed` = 磁石を印刷中の一時停止で完全埋め込み（推奨・断面ツルツル）
- `*_openface` = 一時停止なし。印刷後に磁石を差し込み・瞬接（断面に磁石の丸が見える代わりに最強＆簡単）
- **キャップ2個は同じプレートに並べて置けます**（Ø120×2が入る）→ 4プレートで全部印刷可能

## 磁石

**丸型ネオジム磁石 直径10mm×3mm（N35以上）× 32個**（Amazon「10×3mm 50個」¥1,300前後）
上から持ち上げたとき最も重い下段約350gを磁石4組（約2.5〜3kg）で支えるので余裕十分。

## 最小フィラメント設定（Bambu Studio / P1S・0.4ノズル）

「0.28mm Extra Draft」系ベース＋以下:

| 項目 | 値 |
|---|---|
| 積層高 | **0.28mm**（キャップ2個だけ可変積層・上面0.12〜0.16でドーム綺麗） |
| ウォール | **2周** |
| 上面シェル | **5層**（天面=もう一枚の断面のため） |
| 下面シェル | 4層 |
| インフィル | **8% ジャイロイド**（さらに削るなら稲妻インフィル＋天面6層） |
| サポート | **なし**（全スラブ自立、オーバーハング最大約37°） |
| ブリム | なし |
| アイロニング | **上面のみON**（天面側の断面平滑化・材料増なし） |
| フィラメント | PLA・単色 |
| スカート | 0〜1周 |

**推定消費: 5個合計 約250〜350g**（Ø20cm版の4割）。印刷時間目安: キャップ約3〜4h、縁スラブ約4〜6h、中央スラブ約5〜7h → 累計18〜25h。

## 埋め込み式の一時停止と磁石の入れ方

- ベッド側ポケット: **Z=4.0mmを最初に覆う層の直前**（0.28積層なら15層目／0.2なら21層目）
- 中3枚の天面ポケット: **Z=29.2mmを最初に覆う層の直前**（0.28なら105層目／0.2なら147層目）
- Bambu Studio: 層スライダーを合わせ右クリック → 「一時停止を追加」

**ルールは1パーツにつき棒の「同じ端」だけ**（ベッド側穴は棒の端の極が断面側へ・天面側穴は端と逆の極が断面側へ出る設計）。

| パーツ | 使う棒の端 | 断面の極 |
|---|---|---|
| キャップ【一番下に使う】 | **端A** | 断面側=A |
| 縁スラブ【2層目に使う】 | **端B** | 下面=B・上面=A |
| 中央スラブ【3層目】 | **端B** | 下面=B・上面=A |
| 縁スラブ【4層目に使う】 | **端A** | 下面=B・上面=A |
| キャップ【一番上に使う】 | **端B** | 断面側=B |

下から順に **A・B・B・A・B**。

- 磁石は1本の棒に連ねて両端に目印 → 穴に差して1個残し、**横にずらして**切り離す
- 縁スラブ2枚は同じSTLでも使う端が逆（4層目は裏返し）→ 投入前に「何層目用か」メモ推奨
- 「合い印」ポケットのおかげで各断面は1通りの向きでしか閉じません

## 組み立て

下から キャップ(A側) → 縁スラブ → 中央スラブ → 縁スラブ → キャップ(B側) の順に近づけるだけ。
