# 手順書 — 磁石で割れる球体を作る（Bambu Studio / P1S）

準備から組み立てまでを順に書いた手順書です。数値の根拠は各サイズの GUIDE（`sphere150/` `sphere200/` `sphere50/`）を参照してください。
Bambu Studio のメニュー名は版によって少し違うことがあります（2.x系を想定）。見つからないときは、各手順にある**同じ意味の項目**を探してください。

---

## 0. 全体の流れ

1. 部品を決める（サイズ・埋め込み式か後はめ式か）
2. 磁石と道具を用意する
3. Bambu Studio で読み込む・設定する
4. 一時停止を入れる（埋め込み式だけ）
5. 印刷し、止まったら磁石を入れる
6. 組み立てる

---

## 1. 部品を決める

| 目的 | フォルダ | 印刷するSTL |
|---|---|---|
| 試作（1〜2時間で動作確認） | `sphere50/` | `hemisphere50_m10x3_embed.stl` ×2 |
| 本番 Ø15cm | `sphere150/` | `cap` ×2・`edge_slab` ×2・`mid_slab` ×1 |
| 大きい版 Ø20cm | `sphere200/` | `cap` ×2・`edge_slab` ×2・`mid_slab` ×1 |

- `*_embed`：印刷を途中で止めて磁石を中に閉じ込める。断面がツルツルになる（推奨）
- `*_openface`：止めずに最後まで印刷し、あとから穴に磁石を差して瞬間接着剤で留める。手順は簡単だが、断面に磁石の丸が見える
- **初めてなら、先に Ø50 を1回作る**。一時停止と磁石の向き合わせを安く練習できます

## 2. 用意するもの

- 丸型ネオジム磁石 **φ10×3mm（N35以上）**
  - 必要数：Ø50 は8個、Ø150・Ø200 は32個
  - 50個入りを買っておくと予備になる
- マスキングテープ・油性ペン（磁石の棒と部品に目印を付ける）
- ピンセット（なくても可）
- 後はめ式の場合：ジェル状の瞬間接着剤
- PLAフィラメント（単色）
- **スムース（平滑）PEIプレート**を推奨。梨地プレートだと、下になった断面に梨地模様が付きます

### 磁石の棒を作る（いちばん大事な下準備）

1. 磁石を全部つなげて、1本の棒にする（勝手にくっつく）
2. 棒の**片方の端**にテープを巻いて「**A**」、反対の端に「**B**」と書く
3. 以後、磁石は**必ず棒の端から1個ずつ**使う。外すときは**横にずらす**（真上に引くと穴から磁石が一緒に抜けます）

> 棒の向きさえ守れば、極（N/S）を調べる必要はありません。

---

## 3. Bambu Studio で準備する

### 3-1. プリンターとプレートを選ぶ
1. 左上の「プリンター」で **Bambu Lab P1S 0.4 nozzle** を選ぶ
2. その下の「プレートタイプ」で、実際に載せるプレートを選ぶ
   - スムースPEIなら **High Temp Plate**（スムースPEIはこの名前で表示されることが多い）
3. 「フィラメント」で、使うPLA（例：Bambu PLA Basic / Generic PLA）を選ぶ

### 3-2. STLを読み込む
1. 「ファイル」→「インポート」→「3D/STL/STEP...をインポート」（または Ctrl+I）で読み込む。STLをウィンドウへドラッグしても可
2. **向きは変えない**。STLは印刷する向き（断面が下）で作ってあります。読み込んだときに「単位を変換しますか？」と聞かれたら **いいえ**
3. 同じ部品を2個作る場合：部品を右クリック →「インスタンスを追加」（または Ctrl+C → Ctrl+V）
4. 1枚のプレートに載せる組み合わせ

| サイズ | プレートの分け方 |
|---|---|
| Ø50 | 半球2個を1枚に（一時停止1回で済む） |
| Ø150 | ①cap×2 ②edge×1 ③edge×1 ④mid×1（4枚） |
| Ø200 | 1枚に1個ずつ（5枚） |

- プレートを増やすには、上部の「＋」（プレートを追加）を押す
- 部品が重なったら、右上の「配置」（Aキー）で自動整列

> **プレートごとに一時停止の高さが違うので、別の部品を同じプレートに混ぜない**（cap×2 の同居はOK）

### 3-3. 印刷設定（プロセス）
左の「プロセス」でベースのプロファイルを選び、各タブの値を変えます。右上の「詳細」をONにしないと出ない項目があります。

**ベース**
- Ø150・Ø200：**0.28mm Extra Draft @BBL P1P/P1S**
- Ø50：**0.20mm Standard @BBL P1P/P1S**

| タブ | 項目 | Ø150・Ø200 | Ø50 |
|---|---|---|---|
| 品質 | 積層ピッチ | 0.28 | 0.2 |
| 品質 | アイロニング種類 | **上面**（天面側の断面を平らにする） | 上面（任意） |
| 強度 | 壁ループ数 | 2 | 3 |
| 強度 | 上面シェル層数 | 5 | 既定 |
| 強度 | 下面シェル層数 | 4 | 既定 |
| 強度 | スパースインフィル密度 | 8% | 15% |
| 強度 | スパースインフィルパターン | ジャイロイド | 既定 |
| サポート | サポートを有効化 | **OFF** | OFF |
| その他 | ブリムタイプ | なし | なし |
| その他 | スカートのループ数 | 0〜1 | 0〜1 |

- **ドームをなめらかにしたい場合（cap・Ø50だけ、任意）**：部品を選んで右クリック →「可変積層高さ」→「アダプティブ」→「適用」
  - 可変積層にすると層の高さが変わります。**一時停止は必ず手順4のプレビューで決めてください**
- 設定を変えたら、左上のプロセス名の横の保存アイコンで「magnet-sphere」などの名前を付けて保存すると、次回からそのまま使えます

### 3-4. スライス
右上の「**プレートをスライス**」を押す → 自動でプレビュー画面に変わります。
右下に表示される重量（g）と時間を控えてください。ガイドの推定重量は概算なので、**この値が正しい値**です。

## 4. 一時停止を入れる（`*_embed` だけ）

ふた（ポケットの天井）の高さ：

| 部品 | ベッド側ポケット | 天面側ポケット |
|---|---|---|
| Ø50 半球 | Z=4.0mm（m5x2版は3.0mm） | なし |
| Ø150 cap | Z=4.0mm | なし |
| Ø150 edge・mid | Z=4.0mm | **Z=29.2mm** |
| Ø200 cap | Z=4.0mm | なし |
| Ø200 edge・mid | Z=4.0mm | **Z=39.2mm** |

### 操作
1. プレビュー画面の**右端の縦スライダー**（層スライダー）の上のつまみをクリックし、キーボードの **↑↓** で1層ずつ動かす。スライダー横に「層番号」と「高さ（mm）」が出ます
2. 上の表の高さの近くで、**断面に丸い穴（4個）が見えている最後の層**を探す
3. その**1つ上の層**（穴がふさがり、ふたが張り始める層）に合わせる
4. つまみの横の「**＋**」アイコンを右クリック（または層の上で右クリック）→「**一時停止を追加**」
   - スライダーに印が付けば成功
5. 天面側ポケットもある部品（edge・mid）は、2〜4を**もう1回**行う（一時停止は2つになる）
6. もう一度「プレートをスライス」を押す

> **判断に迷ったら1層早いほうに入れる。** 早い分には磁石は入ります。遅いと、ふたが閉じた後に止まり、その部品は失敗です。
> 層番号を手で計算しないでください。1層目の厚さの設定で番号が1つずれます。

---

## 5. 印刷する

1. 右上の「**プレートを印刷**」→ 送信画面で
   - **「ベッドレベリング」：ON**
   - 「タイムラプス」：任意
   - 「フローダイナミクス校正」：任意
2. 「送信」を押す（LAN／クラウド接続がない場合は「エクスポート」で G-code を microSD に保存し、P1S のSDカードから印刷）
3. 部品ごとに「何層目に使うか」をメモしておく（下の表を使う）

### 5-1. 止まったら磁石を入れる
P1S は一時停止の層でヘッドを退避させて止まり、画面に一時停止が表示されます。

1. 開いている穴が4個あることを確認する
2. 下の表で、その部品に使う**棒の端（A または B）**を確認する
3. 棒のその端を穴に差し込み、端の1個だけを残して、**棒を横にずらして**切り離す
4. 4つの穴すべてに、**同じ端から**入れる
5. 磁石の上面が穴の縁より下にあること（飛び出していないこと）を確認する。出ていたら指で押し込む
6. プリンター画面（または Bambu Handy アプリ）で「**再開**」
7. edge・mid は、天面でもう一度止まる → **同じ端**で2〜6を繰り返す

| 部品（組み立て位置） | 使う棒の端 |
|---|---|
| cap【1層目＝一番下】 | **A** |
| edge【2層目】 | **B** |
| mid【3層目＝中央】 | **B** |
| edge【4層目】 | **A** |
| cap【5層目＝一番上】 | **B** |
| Ø50 半球の片方 | **A** |
| Ø50 半球のもう片方 | **B** |

- edge は2個とも同じSTLですが、**2層目用と4層目用で使う端が逆**です。印刷前にプレート（またはメモ）に「2層目用」「4層目用」と書いておく
- 止めたまま長時間放置すると、ベッドが冷えて部品が浮くことがあります。**止まったらすぐ入れる**

### 5-2. 後はめ式（`*_openface`）の場合
1. 一時停止なしで最後まで印刷する
2. 冷めてからプレートから外す
3. 穴に瞬間接着剤を少量入れ、上の表と同じ端から磁石を差し込む（向きの考え方は埋め込み式と同じ）
4. 接着剤が固まるまで、部品どうしを近づけない（磁石が引っ張られて抜けるのを防ぐ）

---

## 6. 組み立てる

1. 部品が冷めてからプレートを外し、プレートをしならせて剥がす
2. 下から **cap(A) → edge(2層目用) → mid → edge(4層目用・裏返して使う) → cap(B)** の順に重ねる
   - 4層目の edge は、**印刷時に上だった広い面を下に向けて**載せる
3. 断面は平らなので、どの角度でも閉じます。4組の磁石が揃う角度で一番強く付きます

### うまく付かないとき
| 症状 | 原因 | 対処 |
|---|---|---|
| 2枚が反発する | 棒の端を取り違えた | その部品だけ作り直す（埋め込み式は取り出せない） |
| 断面にすき間ができる | ベッド側の縁のはみ出し（エレファントフット） | 縁をカッターかヤスリで軽く削る |
| 天面側の断面が波打つ | アイロニングがOFF、または上面シェルが少ない | 3-3 の設定を確認する |
| 断面にポケットの丸が浮き出る | 一時停止が遅かった／磁石が飛び出していた | 手順4・5-1の確認をやり直す |
