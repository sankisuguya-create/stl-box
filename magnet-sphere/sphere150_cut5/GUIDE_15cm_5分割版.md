# 直径15cm・5分割球体（切れ目指定版）STLキット — 磁石埋め込み式

Ø150mmの球を、**上から32.5mm・75mm・100mm・125mm** の高さで切った5パーツです。
断面同士は磁石で吸着し、磁石は印刷中の一時停止で中に閉じ込めます（埋め込み式）。

```
  上 ── P1 ── 32.5mm ── P2 ── 75mm(赤道) ── P3 ── 100mm ── P4 ── 125mm ── P5 ── 下
```

| パーツ | 範囲（上から） | 厚さ | ベッドに置く面 | 一時停止 |
|---|---|---|---|---|
| `P1`（上キャップ） | 0〜32.5mm | 32.5mm | 下面 Ø123.6 | Z=4.0 |
| `P2` | 32.5〜75mm | 42.5mm | 赤道面 Ø150 | Z=4.0 と **Z=41.7** |
| `P3` | 75〜100mm | 25mm | 赤道面 Ø150 | Z=4.0 と **Z=24.2** |
| `P4` | 100〜125mm | 25mm | 上面 Ø141.4 | Z=4.0 と **Z=24.2** |
| `P5`（下キャップ） | 125〜150mm | 25mm | 上面 Ø111.8 | Z=4.0 |

- STLは**印刷する向き**（各パーツの大きい断面が下）で作ってあります。向きは変えないこと
  - 全パーツが下から上へ細くなるだけなので、**オーバーハングはゼロ・サポート不要**
- 磁石のポケットは各断面に4個、90°ごと（点対称）。円の半径は断面ごとに違い（r=49／65／59／42mm）、合わせる2面は同じ配置です

## 磁石

**丸型ネオジム φ10×3mm（N35以上）× 32個**（4断面 × 2面 × 4個）

## プレートの分け方（4枚）

| プレート | 載せるもの | 一時停止 |
|---|---|---|
| ① | P1 と P5 | Z=4.0 の1回 |
| ② | P2 | Z=4.0 と Z=41.7 |
| ③ | P3 | Z=4.0 と Z=24.2 |
| ④ | P4 | Z=4.0 と Z=24.2 |

P3 と P4 は、一時停止の高さは同じですが、並べると幅256mmに収まらないため別プレートです。

## 印刷設定

`sphere150/GUIDE_15cm版.md` の「最小フィラメント設定」と同じ設定です（0.28mm、壁2周、上面5層、インフィル8%ジャイロイド、サポートなし、上面アイロニング、スムースPEI推奨）。
Bambu Studio の操作は `HOWTO_手順書.md` の 3〜5 を参照してください。

**一時停止を入れる層は、層番号ではなくプレビューで決める**：
穴が最後に見える層の「次の層」の直前に入れます。迷ったら1層早く止めてください。

## 棒のどちらの端を使うか（この版専用・旧版と違うので注意）

| パーツ | 使う棒の端 |
|---|---|
| P1（上キャップ） | **A** |
| P2 | **A** |
| P3 | **B** |
| P4 | **B** |
| P5（下キャップ） | **B** |

上から **A・A・B・B・B**。1パーツの中では、2回の一時停止とも同じ端を使います。
（ベッド側の穴では棒の端の極が断面側に出て、天面側の穴では逆の極が出る。この表のとおりに入れると、向かい合う面の極が必ず逆になります）

## 組み立て

P5（下キャップ）を置き、P4 → P3 → P2 → P1 の順に重ねます。
- P3・P4・P5 は**印刷時と上下が逆**です（印刷時にベッドに付いていた面が上を向く）
- 90°ごとに4か所、磁石4組が揃う角度があります。近づけると一番近い角度に吸い寄せられます

## 推定消費

5個の合計は約350〜450gです（概算）。確定値はスライス後の重量表示で確認してください。
