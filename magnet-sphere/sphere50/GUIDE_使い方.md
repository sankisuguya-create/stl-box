# 直径5cm・磁石つき分割球体 STL

同じSTLを**2個印刷**して、磁石でカチッと合わせる球体です。
両方とも半球の断面は完全に平ら。継ぎ目は髪の毛1本分の細い線だけ見えます。

## ファイルの選び方

| ファイル | 磁石の入れ方 | 断面の見た目 | 保持力 |
|---|---|---|---|
| `hemisphere50_m10x3_embed.stl`（推奨） | 印刷中に一時停止して埋め込む | ツルツル（磁石は見えない） | ◎ |
| `hemisphere50_m6x3_embed.stl` | 同上（φ6×3磁石用） | 同上 | ○ |
| `hemisphere50_m5x2_embed.stl` | 同上（φ5×2磁石用） | 同上 | △ |
| `hemisphere50_m8x3_embed.stl` | 同上（φ8×3磁石用） | 同上 | ◎ |
| `hemisphere50_m6x3_openface.stl` | 印刷後に差し込んで接着 | 磁石の丸が見える | ◎ |

- 本番版（sphere150）と同じ「ネオジム磁石 φ10mm×3mm」を使うなら **`m10x3_embed`**。8個必要。
- 磁石のサイズが他なら `gen_sphere.py` の `SIZES` を変えて再生成できます。

## 印刷設定（P1S・PLA推奨）

- 半球を**断面を下にして**置く（この向きならサポート不要・断面が最もきれい）
- 2個を同じプレートに並べる → 一時停止1回で済む
- 積層 0.2mm（球面をより滑らかにしたい場合は 0.12mm か可変積層）
- 外周3ウォール・インフィル15%・ブリム不要
- できればスムースプレート（梨地プレートだと断面にも梨地がつきます）

## 埋め込み式：磁石の入れ方（ここだけ手順あり）

1. スライサーのプレビューで、ポケットのふたが閉まる直前の層に一時停止を入れる
   - **Z=4.0mm を最初に覆う層**（0.2mm積層なら **21層目**、0.12mmなら **34層目**）
   - Bambu Studio: 右の層スライダーをその層に合わせ → 右クリック → 一時停止を挿入
   - （`m5x2` 版だけ Z=3.0mm → 0.2mm積層で **16層目**）
2. 磁石8個を1本の棒（ロッド状）に連ねておく
3. 停止したらヘッドが退避 → 穴が4つ開いている（深さ約3mm）
4. **片方の半球**: 棒の「端」を穴に差し、端の磁石1個だけを残す。棒を**横にずらして**切り離すのがコツ（真上に引くと磁石がついて出てしまいます）。4穴すべてに同じ端から入れる
5. **もう片方の半球**: 棒をひっくり返して**反対側の端**から同じように入れる
   → これで2つの半球は必ず引き合う向きになります。向きを考える必要はありません
6. 印刷を再開 → あとは自動でふたが閉まる

## 合わせ方

- ポケットは3個＋中心からずれた「合い印」1個の配置。**1通りの向きでしか閉じません**
- 近づけると磁力で勝手に吸い寄せられて正位置に合わさります。回しても磁石同士が合えば正解です

## 後はめ式を使う場合

- 一時停止は不要。印刷後、ポケット（φ6.3・深さ3.15mm）に磁石を差し込むだけ
- 片方は棒の端、もう片方は棒の反対側の端から（向きは埋め込み式と同じ考え方）
- 緩ければジェル状の瞬間接着剤を少量
