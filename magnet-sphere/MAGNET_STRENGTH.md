# 磁力の記録 — 「ちょうどよい」吸着力の再現条件

実物で確かめた結果と、その条件を残す。次に作るとき、または別サイズに展開するときの基準にする。

## 基準：Ø150 5分割版の赤道面（P2／P3）＝ 磁石8組で「ちょうどよい」

2026-10 に印刷・組み立てて確認した（利用者による実物確認。数値測定はしていない）。

| 項目 | 値 |
|---|---|
| モデル | `sphere150_cut5/` P2・P3（`src/gen_cut_sphere.py`、赤道面 `INNER_RING = {0.0: 40.0}`） |
| 断面 | Ø150（赤道） |
| 磁石 | 丸型ネオジム **φ10×3mm**（N35以上を想定。実際の等級：**要記入**） |
| 個数 | 1面8個 × 両面 ＝ **8組** |
| 配置 | 外側 r=65mm に東西南北4個 ＋ 内側 r=40mm に北東・南東・南西・北西4個（中心なし） |
| ポケット | 直径10.5mm・深さ3.2mm（`EMBED_DCLEAR=0.5`／`EMBED_TCLEAR=0.2`） |
| 磁石と断面の間の樹脂 | **片側0.8mm**（`FLOOR=0.8`）→ 磁石どうしの隙間 **1.6mm** |
| 埋め込み方 | 両面ともベッド側ポケット（Z=4.0mmで一時停止） |
| 材料・設定 | PLA、0.28mm積層、`sphere150_cut5/GUIDE` の設定 |
| 計算上の吸着力 | 約0.8kgf/組 × 8組 ≒ **約6.5kgf**（`src/mag_force.py`、理想条件。実物は2〜3割下振れしうる） |

> 天面側ポケットは、磁石が相手側に引かれて天井（0.8mm）に密着するため、隙間は同じ1.6mmになる。

## これまでの結果（判断材料）

| 組み合わせ | 当てた面 | 磁石 | 結果 |
|---|---|---|---|
| P1 単体 | 金属壁（平滑） | 4個 | 少しずつ滑り落ちる |
| P1 単体 | 金属壁（摩擦大） | 4個 | 保持できる |
| P4+P5 | 黒板 | 4個 | 滑り落ちる |
| **P2–P3 の合わせ面** | 磁石どうし | **8組** | **ちょうどよい** |

壁や黒板への張り付きは、磁石と鉄板の吸着×摩擦で決まるため、磁石どうしの合わせ面とは別の指標。

## 再現・展開のしかた

- **同じ強さを再現する**：上の表の条件（磁石・個数・隙間1.6mm）をそろえる。磁石の等級を変えると力も比例して変わる（N35→N52でおよそ1.4倍。根拠：残留磁束密度の比の2乗の概算）
- **隙間を変えたときの力**：`python src/mag_force.py 1.4 1.2` で比率を出す

  | 隙間 | 1.8 | **1.6** | 1.4 | 1.2 | 1.0 | 0.8 |
  |---|---|---|---|---|---|---|
  | 力（1.6mm=100） | 92 | **100** | 109 | 119 | 131 | 145 |

- **別の断面・別サイズへ展開する**：まず「磁石の組数 × 1組の力」を基準の約6.5kgfと比べる。断面が小さく8個入らない場合は、隙間を詰める（上表）か、磁石を大きくする
- **重さあたりで考える場合**：合わせ面より下のパーツの重さ（スライス後の重量表示）を磁石の組数で割り、基準と比べる
