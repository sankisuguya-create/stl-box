# 直径20cm・平行5層スライス球体 STLキット

Ø200mmの球を40mm厚の平行スラブ5枚に切ったもの。断面同士は磁石で吸着します。
STLは**3種だけ**（合計5個印刷）：

| STL | 印刷数 | 使う場所 | 断面 |
|---|---|---|---|
| `sphere200_cap_m10x3_*.stl` | 2 | 一番下(1層目)・一番上(5層目) | 片側Ø160 |
| `sphere200_edge_slab_m10x3_*.stl` | 2 | 2層目・4層目 | 下Ø160／上Ø196 |
| `sphere200_mid_slab_m10x3_*.stl` | 1 | 3層目(中央) | 両側Ø196 |

- `*_embed` = 磁石を印刷中の一時停止で完全埋め込み（推奨・断面ツルツル）
- `*_openface` = 一時停止なし。印刷後に磁石を差し込み・瞬接（断面に磁石の丸が見える代わりに最強＆簡単）

## 磁石（指定）

**丸型ネオジム磁石 直径10mm × 厚さ3mm（N35以上）× 32個**
- Amazonで「ネオジム磁石 10×3mm 50個」で ¥1,300〜1,800前後（1個あたり¥30前後）が最も安い
- ダイソー等の小パックは割高＆サイズが合わないことが多いのでAmazon一括がおすすめ
- 1面あたり4個（3等配＋内側1）× 8面 = 32個。50個パックなら予備つき
- 持ち上げた時の下ぶらり耐荷重: 上から持って約700gの下段を磁石4組（約2.5〜3kg）で支える計算。余裕あり

## 最小フィラメント設定（Bambu Studio / P1S・0.4ノズル）

ベース: 「0.28mm Extra Draft」系プロファイルから以下を変更。

| 項目 | 値 | 理由 |
|---|---|---|
| 積層高 | **0.28mm** | 層数最少化（キャップ2枚だけ可変積層で上面0.12〜0.16にするとドームが綺麗） |
| ウォール周数 | **2** | 装飾モデルには十分（0.8mm壁） |
| 上面シェル | **5層** | スラブ天面＝もう一枚の断面。平面品質を確保 |
| 下面シェル | 4層 | ベッド側断面 |
| インフィル | **8% ジャイロイド** | グラム数の最大レバー。天面のたわみ防止の最低ライン |
| インフィル（さらに削るなら） | 稲妻インフィル | 装飾専用の極少インフィル。天面6層以上＋アイロニング併用推奨 |
| サポート | **なし** | 全スラブ断面を下に置くだけ（オーバーハング最大37°で自立） |
| ブリム | なし | 接地面Ø160〜200で十分すぎる |
| アイロニング | **上面のみON** | 天面側の断面を平滑化（フィラメント増なし・時間だけ増える） |
| 継ぎ目 | 背面 or 整列 | 球面の見た目 |
| フィラメント | PLA・単色 | フラッシュ/パージ損失ゼロ |
| スカート | 0〜1周 | |
| プレート | **スムース（平滑）PEI推奨** | 梨地だとベッド側断面に梨地が付き、アイロニングした天面側と質感が揃わない |

**推定消費: 5個合計 約700〜850g（概算）→ 1kg巻き1本で収まる見込み。確定値はスライス後の重量表示で確認**
印刷時間目安: キャップ 約5〜6h、縁スラブ 約7〜9h、中央スラブ 約8〜10h → 累計30〜40h
Ø200は1プレートに1個しか乗らないので5プレート分。

## 埋め込み式の一時停止と磁石の入れ方

ふたの高さは **Z=4.0mm**（底面ポケット）と、中3枚はさらに **Z=39.2mm**（天面ポケット）。
**止める層は番号でなくプレビューで決める**：層スライダーを動かし、**穴が最後に見える層の「次の層」の直前**に一時停止を入れる（Bambu Studio: 右クリック → 一時停止を挿入）。
- 層番号は1層目の厚さ（0.28系プロファイルでも1層目は0.2mmのことが多い）で1つずれるため、目安にしない
- 迷ったら1層早く止める側に倒す（早い分には磁石は入る。遅いとふたが閉じてその個体は失敗）

**ルールは1パーツにつき棒の「同じ端」だけ**。これだけで全断面が吸着します
（ベッド側穴は「棒の端の極」が断面側に出る・天面側穴は「端と逆の極」が断面側に出るため、下表どおり割り当てれば隣り合う極が必ず逆になります）。

| パーツ | 使う棒の端 | そのパーツの断面の極 |
|---|---|---|
| キャップ【一番下に使う】 | **端A** | 断面側=A |
| 縁スラブ【2層目に使う】 | **端B** | 下面=B・上面=A |
| 中央スラブ【3層目】 | **端B** | 下面=B・上面=A |
| 縁スラブ【4層目に使う】 | **端A** | 下面=B・上面=A |
| キャップ【一番上に使う】 | **端B** | 断面側=B |

つまり下から順に **A・B・B・A・B** です。

- 「端A／端B」: 磁石を1本の棒に連ねたものの**両端**（最初にテープ等で目印を）。棒を穴に差して1個残し、**横にずらして**切り離す
- 縁スラブは2枚とも同じSTLですが、4層目は裏返しで組み込むため使う端が2層目用と逆です → **印刷・投入前に「何層目用か」マスキングテープ等でメモ推奨**

## 組み立て

下から キャップ(A側) → 縁スラブ → 中央スラブ → 縁スラブ → キャップ(B側) の順に近づけるだけ。
断面は平らなのでどの角度でも閉じます（見た目はどの向きでも同じ）。
